# SOC Sentinel AI - Data Flow

## Data Flow

```
Windows Event Logs
        │
        ▼
 Log Collector
        │
        ▼
 Detection Engine
        │
        ├──────────────► Threat Intelligence
        │                      │
        │                      ▼
        │              IOC Verification
        │
        ▼
 MITRE ATT&CK Mapper
        │
        ▼
 AI Incident Analyzer
        │
        ▼
 Report Generator
        │
        ▼
 SOC Dashboard
```

---

## Flow Description

### Step 1

Security events are generated by Windows and Linux systems.

### Step 2

The Log Collector gathers all security events.

### Step 3

The Detection Engine identifies suspicious activities.

### Step 4

Threat Intelligence verifies indicators of compromise (IOCs).

### Step 5

MITRE ATT&CK techniques are identified.

### Step 6

AI explains the incident.

### Step 7

A professional investigation report is generated.

### Step 8

The SOC Dashboard displays the final incident.
