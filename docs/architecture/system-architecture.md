# SOC Sentinel AI - System Architecture

## Overview

SOC Sentinel AI is a modular AI-assisted Security Operations Platform.

The platform collects logs, analyzes security events, maps attacks to the MITRE ATT&CK framework, and generates AI-assisted incident reports.
